# EO VLM Project — Train Qwen2.5-VL-3B on Kaggle (Free GPU)

Fine-tune `Qwen/Qwen2.5-VL-3B-Instruct` with LoRA for Earth-Observation
flood analysis, using LLaMA-Factory on Kaggle's free T4/P100 GPUs.

## STEP 0 — Prepare your dataset locally

1. Collect satellite PNG/JPG chips (~512 px) in a folder `images/`.
2. Create `labels.csv` with one row per image:

```csv
image,region,year,month,has_flood,water_pct,baseline_pct,boxes
patna_2024_09.png,"Patna, Bihar",2024,9,1,35,6,"[[112,340,489,602],[30,88,512,210]]"
jaipur_2024_03.png,"Jaipur, Rajasthan",2024,3,0,3,4,""
```

- `boxes` = list of `[x1,y1,x2,y2]` pixel boxes (empty if no flood)
- Mix ~50% flood scenes / 50% normal scenes from different cities

3. Run the builder:

```powershell
cd eo_vlm_project
python scripts/build_dataset.py --images path\to\images --labels path\to\labels.csv
```

This writes `data/train.json` with balanced question types:
description, bounding-box grounding, and anti-sycophancy refusals.

## STEP 1 — Upload to Kaggle

1. kaggle.com → New Dataset → upload the whole `eo_vlm_project/data/`
   folder **including images** (zip if > 100 files, Kaggle unzips).
   Name it `eo-flood-dataset`.
2. Notebook → New Notebook → Settings:
   - Accelerator: **GPU T4 x2** (or P100)
   - Internet: **ON**

Cell 2 — point LLaMA-Factory at your data:
```python
import os, json, glob, shutil
DATA = "/kaggle/input"   # find your dataset folder under here
hits = glob.glob("/kaggle/input/*/*train.json", recursive=True)
assert hits, "Upload not found - check /kaggle/input contents"
src = os.path.dirname(hits[0])
work = "/kaggle/working/eo"
os.makedirs(f"{work}/data", exist_ok=True)
for f in os.listdir(src):
    shutil.copy(os.path.join(src, f), f"{work}/data/")
print("Dataset ready at", work)
```

Cell 3 — write the training config (T4 = fp16 only, no flash-attn):
```python
cfg = """
model_name_or_path: Qwen/Qwen2.5-VL-3B-Instruct
stage: sft
do_train: true
finetuning_type: lora
lora_rank: 32
lora_alpha: 64
lora_dropout: 0.05
lora_target: all
freeze_vision_tower: true
freeze_multi_modal_projector: true
dataset: eo_flood
dataset_dir: /kaggle/working/eo/data
template: qwen2_vl
cutoff_len: 1024
image_max_pixels: 262144
preprocessing_num_workers: 4
output_dir: /kaggle/working/saves/eo-lora
logging_steps: 10
save_steps: 200
plot_loss: true
per_device_train_batch_size: 1
gradient_accumulation_steps: 8
learning_rate: 1.0e-4
num_train_epochs: 3.0
lr_scheduler_type: cosine
warmup_ratio: 0.03
fp16: true
bf16: false
gradient_checkpointing: true
report_to: none
val_size: 0.1
per_device_eval_batch_size: 1
eval_strategy: steps

"""
open("/kaggle/working/train.yaml","w").write(cfg)
# copy dataset_info.json next to train.json
shutil.copy(glob.glob("/kaggle/input/**/dataset_info.json", recursive=True)[0],
            "/kaggle/working/eo/data/dataset_info.json")
```

Cell 4 — TRAIN (~3-6 hrs for ~2k samples; use ONE gpu for stability):

## Common failures

| Symptom | Fix |
|---|---|
| CUDA out of memory | keep batch=1, lower `image_max_pixels`, confirm vision tower frozen |
| fp16 loss NaN | lower LR to 5e-5 |
| `template not found` | you must use `qwen2_vl` exactly |
| slow epochs | normal on T4; P100 is ~1.5x faster |
| quota exhausted (30h/wk) | resume: reattach saved zip, set `adapter_name_or_path` and continue |
